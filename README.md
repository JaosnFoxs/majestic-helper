# Majestic Helper

Оверлей-памятка по законам и правилам Majestic RP: быстрый поиск по статьям, закрепление в памятку, работает поверх игры в режиме «Окно без рамки».

**Скачать:** раздел [Releases](../../releases/latest) → `MajesticHelper-win64.zip` → распаковать → `MajesticHelper.exe`.

Показать/скрыть окно: `Ctrl+Shift+L`. Данные (настройки, памятка, кэш) лежат в папке `data` рядом с `.exe`.

## Как это устроено
- `Release` (Actions): при изменении кода собирает `.exe`, `app.zip` (автообновление) и `version.json` и выкладывает релиз.
- `Data` (Actions): раз в час собирает базу законов и правил в релиз `data/snapshot.json`; программа скачивает один этот файл.
- Если базы нет, программа сама читает docossum.com и форум.

## Разработка
`npm install`, `npm start`, `npm test`. Новая версия: поменять номер в `app/version.json` и закоммитить в `main` — релиз соберётся сам.
